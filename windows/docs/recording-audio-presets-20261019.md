# 录制、音量与场景预设更新

适用于当前源码版本 **0.1.2-win.3**。完整功能说明见 [Windows 使用说明](../README.md)。

## 使用变化

- 提词器可以拖动边缘或角点缩放。摄像头预览默认位于主屏右上角；录制完成后，保存的摄像头素材会在编辑器中显示。
- 成功停止录制后，主控台与素材整理面板保持隐藏，只显示右下角完成卡片。项目已自动保存，卡片会显示保存位置，并提供“保存项目…”（复制项目）和“进入编辑”。
- 麦克风全局音量和片段音量范围为 0–400%，新项目默认 100%；已保存的旧项目音量值会保留。系统声音范围为 0–100%。Windows 音量合成器中的 Recly 应用音量单独控制本机播放，不等同于项目音轨增益；软件不会自动把系统应用音量设为 100%。
- 新录屏沿用上次显式选择的已保存场景预设。项目中的临时外观调整不会自动写回预设；对已设为新录制默认的预设，点“更新此预设”后，新录屏才使用更新内容。打开旧项目若匹配到其他预设，需先显式选择该预设或将它设为新录制默认；打开旧项目不会套用或覆盖默认预设。默认选择在重新启动后仍会保留。

## 验收范围

- 在实际打包版编辑器中连续播放约 30 秒并调节音量 66 次，播放时间持续前进，麦克风和摄像头没有因音量调整触发暂停或重新定位。另以真实项目副本进行只读播放检查，项目文件与素材保持不变。
- 打包版增益节点测量中，麦克风 100%、200%、400%分别对应约 1、2、4 倍线性增益；导出按片段设置应用相同的音量系数。该比例说明信号幅度变化，不代表所有素材都不会底噪增大或削波。
- 实际包的编辑界面保存 160% 后，关闭并重新打开仍为 160%；新建合成项目的麦克风默认值为 100%。合成信号检查与真实项目播放检查是不同验收项，合成结果不代表所有设备或录音环境的表现。
- 默认预设的保存与重启行为通过实际打包版验证；录制整理使用合成屏幕素材，不代表实体屏幕或麦克风采集验收。

视频预览的软件解码与 GPU 画布组合是当前 Windows 环境的兼容性修复。验收不代表所有硬件都能满帧，也不构成耳机口型或整体性能保证。
