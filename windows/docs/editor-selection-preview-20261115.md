# 时间线选择、流畅预览与录制交接更新

日期：2026-11-15。适用于当前 Windows 源码。本文记录功能及本机验证范围。

## 操作变化

- 在轨道空白处按住左键拖动，框选相交的录屏、字幕、音频和效果片段；框选不移动播放头。拖动时间标尺仍可移动播放头。
- Ctrl+A 全选各轨素材，Delete 或工具栏删除所选内容。批量删除只产生一个撤销点，Ctrl+Z 可恢复。输入框内的 Ctrl+A 保持文本全选。
- 可以单独删除最后一个录屏片段，也可删除所有素材。空时间线停止播放、清空预览，保存重开不会恢复已删片段；有内容后再导出。
- 导入音频可用 S、Ctrl+B 或工具栏分割，支持撤销重做。Ctrl+滚轮、缩放按钮和滑杆统一支持缩至适应宽度的 50%。
- 原“原画预览”按钮位置改为全屏观看；Esc 或再次点击退出。移除预览区加号菜单，拖入图片和剪贴板粘贴保留。

## 录制与播放

打开软件或修改录制设置后预热采集条件，启用的音频与摄像头输入提前就绪。实际采集仍须等待真实首帧，不能保证零延迟。待机输入不写入录制文件。

麦克风文字独立居中，电平条位于底部；点击短暂显示当前设备并执行开关，右键可选设备。摄像头悬浮窗由显式开关控制；有实时画面时隐藏摄像头提示文字。录制中可切换设置页，提词器阅读态正文支持鼠标穿透。

实际录制时任务栏图标显示红点。停止录制清除红点，整理素材期间保留任务栏入口；编辑器显示后才隐藏录制器。此前收进托盘的录制器恢复为不抢焦点的最小化窗口。

新录制在整理阶段并发准备缩略图和代理视频，再统一保存工程并打开编辑器。默认使用代理预览，导出继续读取原始素材。代理保持 1280 像素宽、60 帧和约一秒的关键帧间隔；支持的 NVIDIA 环境优先使用 CUDA 解码及缩放、NVENC 编码，失败时回退到普通解码及硬件编码，再回退软件编码。代理大小和修改时间用于判断缓存是否可复用。

## 验证与边界

本机合成的 12 秒、2560×1440 / 60 帧素材，旧流程约 3.70 秒，新流程约 1.92 秒，耗时减少约 48%。代理为 H.264、1280×720 / 60 帧，时长与关键帧间隔核对、完整解码通过。该结果只代表此素材和电脑，不保证所有录制都有相同加速比例。

真实 Electron 鼠标及键盘验收通过：跨轨框选且播放头不动，Ctrl+A 全删，一次撤销恢复，单删最后一个录屏片段，空工程保存重开，全屏与 Esc 退出。最终包隔离实录也验证了预览初始使用代理、顶部没有准备提示、停录至编辑器就绪的约三秒交接期间 149 次原生窗口采样均保留任务栏入口。窗口状态采样不等同于逐帧检测 Windows 任务栏像素。

完整回归使用：

```powershell
cd windows
npm run test:regressions
```
