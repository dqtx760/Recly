## 验证结果

- 回归命令 `npm test` 通过；独立审查发现的 W 重排后播放头跳转、末端粘贴不可见片段已修复并通过复审和专门测试。
- 实际 Electron 编辑器验证分割、Q/W、吸附开关、缺口恢复、拖动重排、波形、独立音量、贴图导入、样机选择、效果复制、贴图分割、开场开关。
- 每批写入项目后重新加载页面，比对磁盘项目与重开状态；撤销 / 重做恢复相应剪辑和效果数据。
- 6 秒带三种画面和三种音频频率的素材，重排且第一段 2× 后成为 5 秒成片。预览音视频时钟偏差小于 0.2 秒的验收阈值；成片 0.3 / 1.3 / 3.3 秒分别解出蓝 / 红 / 绿画面及 1320 / 440 / 880 Hz 音频。第一段音量比例实测 `0.27761`，目标 `0.25 / 0.9 = 0.27778`。
- 五个实际导出均为 150 帧、5 秒、30 FPS，并通过 FFmpeg 完整解码。
- 第二批在偏移缩放 + 裁切 + 光标 + 样机 + 柔化 + 真 PNG 贴图组合下，三个时点的预览 / 导出画布 RGB 平均差为 0。
- 第三批覆盖输出开场、2 秒视频背景跨循环、屏幕运动和贴图衔接、摄像头取景；对应时点的画布 RGB 平均差小于 0.13 / 255。动态视频单帧采样有微小差异，未发现布局或时间映射不一致。
- 真实帧发现 3D 三角网格漏缝，已用三角裁剪重叠与原四边形总裁剪修复；极端 80° / -80° 倾斜的顶点外移限制在 2 像素，普通和极端投影回归均通过。修复后的实际帧已目视检查。
- 打包的 `app.asar` 中 20 个相关源码文件与工作区字节一致；版本与透明 ICO 已核对，图标角落 Alpha 为 0。用包内编辑器源码重复运行三批交互、保存重开、预览和导出流程，通过。
- 只读打开用户的 `录屏 2026-10-10 18.46.13.dogscproject`，正常绘制首帧与全部效果轨；未写回用户工程。

## 性能与实际限制

960×540、30 FPS、5 秒组合测试的导出约 2.3–4.7 秒，包含额外像素比对与截图写入。该短片结果不能外推为 1440p / 4K 长片的速度保证，也不是与上一版本的同场景测速。

测试输入必须有完整色彩标记。FFmpeg 的颜色参数在本机并未完整写入 H.264 SPS，使用 `h264_metadata` 补齐后，预览与导出才得到一致的色彩解释。无标记或不完整标记的外部视频仍可能有解码色差。

部分编码后的窗口 `capturePage()` 诊断截图返回 `UnknownVizError`；画布帧、成片解码和重开的实际编辑器截图均正常。这项诊断接口失败没有被当作导出成功证据。

字幕、自动语音识别、语音跟随提词器和 3D 聚焦虚化不属于本次已完成能力。
