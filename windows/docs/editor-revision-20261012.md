# Recly 编辑器与录制流程修订验收

日期：2026-10-12。打包版本：`0.1.2-win.3`。

## 已完成

- 画面设置分为背景、布局、样机三个页签；切换保留各页滚动位置。
- 浏览器样机支持自定义地址文字，按原作者参数调整框体、顶栏、圆角默认值。旧工程显式参数保留。
- 屏幕 3D 改用画面矩形与偏移插值，补构图锚点、焦点约束、投影中心和连续片段衔接；新增片段有进入及退出运动。预览与导出使用同一场景求值。
- 左侧不再单独列出叠加；通过预览区 +、图片拖入、粘贴截图添加贴图。可直接拖动、缩放和旋转，设置录屏虚化、仅背景显示。
- 剪辑后播放等待画面时，主视频继续 seek 解码，音轨等待画面；修复暂停主视频造成的永久等待。
- Electron 44 剪贴板改用异步 ClipboardItem 接口。有图片时 Ctrl+V 导入，无图片时保留效果粘贴。
- 桌面 / 区域录制可隐藏桌面图标，结束时恢复原状态；窗口录制不启用此设置。
- 录制结束回到待机，右下角完成卡提供保存项目和进入编辑，不自动开编辑器，可连续录多段。
- 另存完整项目先复制为 `.partial`，成功后改名为项目包；不覆盖原项目。复制失败保留未完成目录，不向项目库暴露损坏副本。
- 录制中关闭控制台改为隐藏，重开复用会话；开始和整理阶段有互斥门闩；未完成录制时托盘退出禁用，退出请求提示先结束录制。

- 用户提供的 `录屏 2026-10-11 23.06.47.dogscproject` 只复制到诊断目录测试，原工程未写回；包内代码完成原始播放、画布修改、分割、裁切、重排、撤销、重做七类检查，均可前进播放，音视频偏差处于 0.2 秒验收阈值内。

## 当前边界

iPhone / iPad 原生有线采集尚未实现。本机未连接 iOS 设备；Windows 不具备原作者 macOS CoreMediaIO 的同等端点。投屏接收器 + 窗口录制是待实机验证的方案，详见 [设备调研](ios-device-recording-20261011.md)。

字幕编辑、自动识别字幕、语音跟随提词器和屏幕 3D 聚焦虚化尚未接入。本次没有承诺与 Mac 原版在所有视觉、性能和剪切衔接细节上完全一致。
